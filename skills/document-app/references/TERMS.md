# UI element terms

Name a control by the established term of the document's language, taken from this table.
The `UI element` column holds the canonical English name — the one the control's type carries
in the code — and doubles as the English wording. A new language joins as a new column; a
control missing from the table joins as a new row.

| UI element     | cs                  |
| -------------- | ------------------- |
| checkbox       | zaškrtávací políčko |
| radio button   | přepínač            |
| button         | tlačítko            |
| toggle         | přepínací tlačítko  |
| text box       | textové pole        |
| drop-down list | rozbalovací seznam  |
| combo box      | kombinovaný seznam  |
| list box       | seznam              |
| tree view      | strom               |
| tree node      | uzel stromu         |
| tab            | záložka             |
| menu           | nabídka             |
| menu item      | položka nabídky     |
| context menu   | místní nabídka      |
| toolbar        | panel nástrojů      |
| status bar     | stavová lišta       |
| dialog         | dialogové okno      |
| tooltip        | popisek             |
| slider         | posuvník            |
| spinner        | číselník            |
| progress bar   | ukazatel průběhu    |
| scroll bar     | posuvná lišta       |
| table          | tabulka             |
| column header  | hlavička sloupce    |
| icon           | ikona               |
| panel          | panel               |
| window         | okno                |
