Interview the user about their plan until you share a complete understanding of it.

- Walk every branch of the design and settle each decision, one at a time.
- Ask one question per message and wait for the answer before asking the next.
- For each question, give your recommended answer.
- If a question can be answered by reading the code, read the code instead of asking.

When every decision is settled, summarise the plan.
