# vertical-slice-architecture

These notes are for anyone modifying this skill. They are intentionally kept out of the skill folder
([`SKILL.md`](../../skills/vertical-slice-architecture/SKILL.md) holds only the instructions the
invoking agent needs), so an agent can't load them.

## Editing guidelines

### Keep the skill stack-agnostic

The slicing rules hold for any language, framework or platform. The `Layout` section uses generic
folder names for that reason; no framework-named examples, no stack-specific vocabulary.
